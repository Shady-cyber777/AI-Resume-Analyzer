\# AI Resume Analyzer



An AI-powered resume analysis tool built with Python, Streamlit, and Ollama.



\## Features



\- Upload a resume PDF

\- Paste a job description

\- Get an AI-generated resume match analysis

\- Shows match score, matching skills, missing skills, resume suggestions, and interview prep questions

\- Runs locally using Ollama with no external API key



\## Technologies Used



\- Python

\- Streamlit

\- pypdf

\- Ollama

\- llama3.2



\## How to Run



Install the requirements:



```bash

py -m pip install streamlit pypdf ollama
